# Screenshots

Images shown in the main README. Capture them at 1920×1080 (or 2560×1440), in
fullscreen, with the default Midnight Violet theme and the wave background,
and save them here as PNG with these names:

| File | What to show |
| --- | --- |
| `library-shelves.png` | Library, Shelves view, All Platforms, a game selected in the spotlight |
| `library-grid.png` | Library, Grid view, All Platforms (sections per system) |
| `library-list.png` | Library, List view with the preview pane |
| `library-carousel.png` | Library, Carousel view |
| `game-details.png` | Game Details of an installed game, with the "Ready to play" line under Play |
| `settings.png` | Settings › Appearance (theme tiles and live preview) |
| `first-time-setup.png` | First-time setup, step 2 (Add games) with found games |
| `add-games.png` | Settings › Library › Add games, or dropping files onto the Library |

Keep personal folder names out of view where possible. Covers and screenshots
of games belong to their publishers and are shown only to illustrate the app.
