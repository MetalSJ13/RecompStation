## Downloads (64-bit Linux, x86_64)

| File | What it is |
| --- | --- |
| `RecompStation-VERSION-x86_64.AppImage` | One file: make it executable and run it. |
| `RecompStation-VERSION-linux-x86_64.zip` | Portable folder: unzip anywhere and run `./RecompStation`. |

Both include Qt, so nothing else needs installing. Each file's SHA-256 is listed in `SHA256SUMS` and shown next to the file on this page.

If the AppImage doesn't start, your system may be missing FUSE 2 (`libfuse2`, or `libfuse2t64` on Ubuntu 24.04); install it, run the AppImage with `--appimage-extract-and-run`, or use the zip.

> [!IMPORTANT]
> RecompStation does not include, host or distribute any game files, ROMs or copyrighted assets. You need your own legally obtained copies of the games.
