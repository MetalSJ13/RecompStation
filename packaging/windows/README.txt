RecompStation - portable Windows build (x86_64)
================================================

Start it with RecompStation.exe in this folder.

Qt and the other libraries RecompStation needs are included, so nothing has to
be installed. The folder can live anywhere and be moved; keep its contents
together.

Your settings, library database, covers and installed launchers are kept in
%LOCALAPPDATA%\RecompStation, not in this folder, so you can replace this
folder with a newer version without losing anything.

This build isn't signed yet, so Windows SmartScreen may warn the first time
you start it ("Windows protected your PC"). Choose "More info", then
"Run anyway".

RecompStation's license is in LICENSE.txt; the libraries included with it
(Qt and others) and their licenses are listed in THIRD_PARTY_NOTICES.md.

RecompStation does not include, download or distribute any game files. You
need your own legally obtained copies of the games.
